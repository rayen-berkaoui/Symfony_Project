# 🌍 SmartTravel - Application de Voyage et Loisirs

## 📖 Description

SmartTravel est une application qui aide les utilisateurs à découvrir facilement des lieux à visiter, des restaurants et des activités dans une destination donnée.  
L’objectif principal est de simplifier l’expérience des touristes en regroupant toutes les informations utiles dans une seule application.

Au lieu de chercher dans plusieurs applications ou sites, l’utilisateur peut tout trouver au même endroit et organiser son séjour plus facilement.

---

## 🎯 Objectif du projet

- Faciliter la découverte de nouveaux endroits
- Aider les utilisateurs à organiser leurs sorties et voyages
- Offrir une expérience simple, rapide et agréable
- Centraliser les informations importantes dans une seule plateforme

---

## 👥 Fonctionnalités principales

### 🔹 Gestion des utilisateurs
- Création de compte
- Modification des informations
- Gestion du statut (actif / bloqué)
- Attribution de rôles

### 🔹 Gestion des rôles
- Différents types d’utilisateurs (admin, utilisateur, partenaire)
- Accès différent selon le rôle

### 🔹 Réservations
- Réserver des activités ou services
- Modifier ou annuler une réservation

### 🔹 Favoris
- Ajouter des lieux en favoris
- Consulter ses préférences

---

## 🧠 Idée générale

L’application est conçue pour être simple et intuitive.  
Elle permet à un utilisateur, même sans connaissance de l’endroit, de trouver rapidement les meilleures options disponibles.

Le projet est aussi pensé pour évoluer facilement avec de nouvelles fonctionnalités comme des recommandations personnalisées.

---

## 🗂️ Structure du projet

Le projet est organisé de manière claire avec :
- des classes pour représenter les données (utilisateur, rôle, etc.)
- des services pour gérer les opérations
- une interface (console ou graphique)

---

## 🛠️ Technologies utilisées

- Symfony
- MySQL
- JDBC (connexion base de données)
